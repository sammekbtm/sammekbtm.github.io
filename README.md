# sammekBTM · Borsa Takip Merkezi

Borsa İstanbul (BIST) tüm hisseler: en çok işlem görenler, en çok alınanlar, yükselen/düşenler, kırılım radarı, hisse detayında grafik, kural tabanlı "Özet / Potansiyel" ve ilgili haberler.

- Fiyatlar: Yahoo Finance (~15 dk gecikmeli). Haberler: Google Haberler RSS. Hisse listesi: İş Yatırım.
- `scripts/update.py` GitHub Actions ile seans saatlerinde ~5 dk'da bir çalışır ve siteyi yeniden yayınlar.
- Yatırım tavsiyesi değildir.
